The server folder consists of java files that live on the server that the client will interact with via specific provided methods

UserAPI.java - handles and processes requests related to user
1. Create Account
2. Login to Account
3. Show Account Info

RestaurantAPI.java - handles and processes requests related to restaurants
1. Return Restaurant Search Results
2. Search and Filter Results

ReservationAPI.java - handles and processes requests related to reservations
1. Show available reservations for a specific restaurant
2. Select & Confirm reservation

DatabaseAPI.java - handles and processes SQL/Database requests from the other java files above
